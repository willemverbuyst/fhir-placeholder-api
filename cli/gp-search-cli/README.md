# GP Search Cli

## What is this?

Tool to get all the practitioners from the fhir-data db. For each practitioner it gets the name as a one-liner from the fhir-name-service. It also gets the organization (via include?). Seed the gp-name-db.

## Docker

As these services and dbs are in a docker environment, this cli tool needs to be in the docker setup as well.
